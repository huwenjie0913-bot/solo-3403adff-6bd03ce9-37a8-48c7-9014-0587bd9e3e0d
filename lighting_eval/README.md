# 文物摄影布光评估

面向展柜纸质文物摄影场景的布光评估网页：在可缩放平面图上拖放展柜、背景与灯具，
按逆平方衰减与视线遮挡计算各拍摄面的照度分布，并给出均匀度、阴影率、眩光与
累积光剂量指标，支持热区追溯、方案保存/叠加比较与 SVG/JSON 导出。

## 运行

```bash
pip install -r requirements.txt
python app.py          # http://localhost:5000
```

首次启动会自动创建 `lighting.db`（SQLite，保存方案配置与评估快照）。

## 功能

- **平面图**：滚轮缩放、拖空白平移；展柜/背景/灯具/相机均可拖放（5cm 吸附）。
- **设备参数**：功率、色温、光束角、光效、安装高度、瞄准点、旋转、透明度/遮挡关系。
- **评估目标**：目标照度上下限、均匀度下限、单日照射时长、光敏度预设（纸质 50 lx /
  120 000 lx·h·年，可改）。
- **指标**：每个拍摄面（展台面 + 背板）的平均/最小/最大照度、均匀度 U0、阴影率、
  年累积剂量、色温加权等效损伤剂量；摄像机眼位眩光（可见灯具垂直照度之和）。
- **网格热区**：绿=达标，橙=低于目标下限，红=超上限/光敏阈值；点击热区点可追溯
  每盏灯的贡献照度、占比与参数。
- **锁定灯位**：单灯锁定或一键锁定全部，锁定后不可拖动，便于试排其余设备。
- **方案管理**：保存/载入/删除；两方案指标差异表（Δ 着色）；方案 B 可虚线叠加在画布上。
- **导出**：带尺寸标注与告警列表的 SVG 图；含配置与指标的 JSON 文件。

## 计算模型（简化假设）

- 灯具为点光源：光通量 Φ = 功率 × 光效；光束角内光强按余弦平方衰减，束外为 0；
  照度 E = I(θ)·cos(入射角)/r²。
- 遮挡：平面图上对“灯→采样点”线段与设备矩形求交（Liang–Barsky），交点处射线高度
  低于设备高度即被遮挡；不透明设备完全阻挡，玻璃展柜按透过率（默认 0.9）衰减。
- 眩光为简化指标（眼位垂直照度），未实现完整 UGR；蓝光损伤权重为色温的线性近似。
- 采样网格间距可调（默认 0.25 m），展台面 z=0.1 m，背板为展柜后缘竖直面。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/evaluate` | 评估配置，返回各面指标与热区点 |
| POST | `/api/trace` | 单采样点的灯具贡献追溯 |
| GET/POST | `/api/schemes` | 方案列表 / 保存 |
| GET/DELETE | `/api/schemes/<id>` | 读取 / 删除方案 |
| POST | `/api/compare` | 两方案指标差异 |
| POST | `/api/export.svg` | 导出 SVG 评估图 |
