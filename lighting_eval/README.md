# 文物摄影布光评估

面向展柜纸质文物摄影场景的布光评估网页：在可缩放平面图上拖放展柜、背景与灯具，
按逆平方衰减与视线遮挡计算各拍摄面的照度分布，并给出均匀度、阴影率、眩光与
累积光剂量指标；针对玻璃压片/覆膜作品，按反射定律试排“灯→反射面→镜头”的
镜面反射光路，定位入画光斑的来源灯具与命中面。支持热区追溯、方案保存/叠加
比较与 SVG/JSON 导出。

## 运行

```bash
pip install -r requirements.txt
python app.py          # http://localhost:5000
```

首次启动会自动创建 `lighting.db`（SQLite，保存方案配置与评估快照）。

## 功能

- **平面图**：滚轮缩放、拖空白平移；展柜/背景/灯具/相机均可拖放（5cm 吸附）。
- **设备参数**：功率、色温、光束角、光效、安装高度、瞄准点、旋转、透明度/遮挡关系。
- **反射面参数**：每个展柜的展台面、背板、玻璃前表面分别记录法线（由位姿推导）、
  反射率与粗糙度，可在展柜属性中按面调整。
- **相机模型**：眼位 + 朝向（yaw）/俯仰（pitch）+ 焦距 + 画幅（全画幅/APS-C/4/3/
  中画幅预设或自定义传感器尺寸），实时显示水平/垂直视场角。
- **反射路径试排**：对每盏灯 × 每个反射面用镜像法求反射光路，给出命中点、
  入射角/反射角、光斑范围（粗糙度→散射半角估算）与是否入画；画布可切换
  镜头视场扇形与反射光路（红=入画，灰虚线=视场外），点击光斑查看光源、
  命中面与角度；移动灯具/相机或旋转展柜时同步刷新。
- **评估目标**：目标照度上下限、均匀度下限、单日照射时长、光敏度预设（纸质 50 lx /
  120 000 lx·h·年，可改）。
- **指标**：每个拍摄面（展台面 + 背板）的平均/最小/最大照度、均匀度 U0、阴影率、
  年累积剂量、色温加权等效损伤剂量；摄像机眼位眩光（可见灯具垂直照度之和）；
  入画光斑数量、覆盖面积与最严重来源。
- **网格热区**：绿=达标，橙=低于目标下限，红=超上限/光敏阈值；点击热区点可追溯
  每盏灯的贡献照度、占比与参数。
- **局部固定**：灯具/展柜/背景/相机均可单独锁定（另有一键锁定全部灯具），
  锁定后不可拖动，便于固定部分设备、试算机位或其余灯位。
- **方案管理**：保存/载入/删除；两方案指标差异表（Δ 着色，含入画光斑数量、
  覆盖面积、最严重来源对照）；方案 B 可虚线叠加在画布上。
- **导出**：带尺寸标注、视场扇形、反射光路与告警列表的 SVG 图；含配置与指标的
  JSON 文件。

## 计算模型（简化假设）

- 灯具为点光源：光通量 Φ = 功率 × 光效；光束角内光强按余弦平方衰减，束外为 0；
  照度 E = I(θ)·cos(入射角)/r²。
- 遮挡：平面图上对“灯→采样点”线段与设备矩形求交（Liang–Barsky），交点处射线高度
  低于设备高度即被遮挡；不透明设备完全阻挡，玻璃展柜按透过率（默认 0.9）衰减。
- 眩光为简化指标（眼位垂直照度），未实现完整 UGR；蓝光损伤权重为色温的线性近似。
- 采样网格间距可调（默认 0.25 m），展台面 z=0.1 m，背板为展柜后缘竖直面。
- 镜面反射：相机关于反射面的镜像与灯具连线交面于命中点（反射定律），仅计算
  一次反射且灯与相机须位于面法线同侧（柜内灯不产生玻璃前表面反射）；两段光路
  均做遮挡判断，命中点须落在灯具光束内。光斑半径 ≈ 散射半角/(1/r灯+1/r相机)，
  掠射方向按 1/cos(入射角) 拉长并截断到面边界；反射强度 = 命中点照度 × 反射率
  ×（1 − 0.6·粗糙度），仅用于来源排序。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/evaluate` | 评估配置，返回各面指标、热区点与反射光路（`reflections`） |
| POST | `/api/trace` | 单采样点的灯具贡献追溯 |
| GET/POST | `/api/schemes` | 方案列表 / 保存 |
| GET/DELETE | `/api/schemes/<id>` | 读取 / 删除方案 |
| POST | `/api/compare` | 两方案指标差异（含反射光斑对照） |
| POST | `/api/export.svg` | 导出 SVG 评估图（含视场、反射光路与告警） |
